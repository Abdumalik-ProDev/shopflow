# ShopFlow Machine Learning Engineering

Production-oriented Machine Learning system for ShopFlow, covering demand forecasting, delivery ETA prediction, and personalized recommendations using the Brazilian Olist e-commerce dataset.

## Directory Layout

```
ml/
├── data/
│   ├── raw/olist/          # Historical Olist raw CSV datasets
│   ├── cleared/            # Cleaned, validated Parquet & CSV datasets
│   └── clean_data.py       # Data cleansing & feature preparation script
├── features/
│   ├── __init__.py         # Feature engineering & dataset loaders
│   └── customer_features.py# RFM feature calculations
├── pipelines/
│   ├── delivery_eta_pipeline.py       # Delivery ETA regression (XGBoost/LightGBM)
│   ├── demand_forecasting_pipeline.py # Daily units demand forecast (XGBoost/LightGBM)
│   └── recommendation_pipeline.py     # Product popularity baseline & ranking
├── training/
│   ├── train_all.py                   # Master entrypoint for all pipelines
│   └── train_recommendations.py       # Standalone recommendation training
├── evaluation/
│   └── metrics.py                     # MAE, RMSE, R2, accuracy metrics
├── inference/
│   └── delivery_eta_inference.py      # Real-time inference & recommendation helpers
├── notebooks/
│   ├── 01_data_exploration.ipynb      # EDA on historical Olist tables
│   ├── 02_feature_engineering.ipynb   # Customer RFM and order feature extraction
│   ├── 03_delivery_eta_model.ipynb    # Delivery duration modeling
│   ├── 04_recommendation_model.ipynb  # Recommendation ranking benchmarks
│   └── 05_model_evaluation.ipynb     # Model validation & residual analysis
├── pyproject.toml                     # Python dependencies & build config
└── uv.lock                            # Reproducible lockfile
```

## Data Separation (per VISION.md §5)

- **`ml/data/raw/olist/`** → Historical Olist data used strictly for ML training. Kept isolated from live marketplace activity.
- **`ml/data/cleared/`** → Cleansed Parquet and CSV files generated by `clean_data.py`.
- **Live Marketplace Data** → Stored in PostgreSQL, seeded via `backend/scripts/seed_olist.py`.

## Running ML Pipelines

```bash
cd ml

# 1. Sync dependencies with uv
uv sync

# 2. Clean raw Olist CSVs into ml/data/cleared/
uv run python data/clean_data.py

# 3. Run all training pipelines and log to MLflow
uv run python -m training.train_all

# 4. Launch Jupyter Lab for notebooks exploration
uv run jupyter lab notebooks/
```

## Tracked ML Capabilities

1. **Delivery ETA Regression**: Compares baseline mean, XGBoost, and LightGBM models predicting order transit time in days.
2. **Demand Forecasting**: Daily order volume time series with lag and rolling window features evaluated with MAE, RMSE, and $R^2$.
3. **Recommendation Engine**: Historical revenue and volume ranking benchmarked across 32,000+ catalog items.
